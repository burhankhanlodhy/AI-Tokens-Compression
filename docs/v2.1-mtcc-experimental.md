# MTCC experimental implementation

The `proxy.mtcc` module exposes a deterministic prompt-view transform and a bounded in-process exact-source store. Callers must supply trusted tenant, API-key, and session scope; request metadata is not read by MTCC. The strategy flag `V21_MTCC_ENABLED` remains false by default and this module is not wired into the proxy request path.

Recent turns stay verbatim. Older system/developer turns, user constraints, error/failure turns, tool turns, and turns that reference tool output stay verbatim. Other older turns are represented in an inspectable facts envelope with source references; low-relevance filler is collapsed to a reference-bearing count. The store retains originals until TTL expiry; at its configured bound, new saves fail rather than evicting unexpired source turns. This first implementation uses process-local memory, so it is not restart-persistent or shared across workers; do not enable in deployments needing durable retrieval.

## Synthetic replay (not a quality gate)

`replay_fixture_sessions()` replays deterministic generated fixtures. On 2026-09-24, 30 sessions × 10 turns (300 turns) reported -19.93% estimated context reduction (the structured/reference envelope expanded this synthetic workload), 2,560 estimated policy-overhead tokens, 15.91 ms aggregate local transform time for the recorded run, and $0 provider summarizer cost because no model summarizer is called. Token counts use a stable byte/4 proxy, not a provider tokenizer. This synthetic fixture measures algorithm behavior only; it does not establish task-success regression, wrong-file/wrong-error diagnosis rates, or production latency.

Therefore the ratified acceptance gate is inconclusive: no representative 30-session paired task-quality replay, no provider-token/cost accounting, and no diagnosis-quality data. Keep MTCC off. The gate additionally requires PostgreSQL-backed persistent storage before deployment use, integration with trusted authenticated session scope, and independent QA on the combined candidate.
