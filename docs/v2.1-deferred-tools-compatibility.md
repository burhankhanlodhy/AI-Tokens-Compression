The shared request contracts accept full `tools` arrays; they do not define a
catalog-only request, a search request, or a deferred-schema resolution response.
No provider is marked compatible in `proxy.deferred_tools`. Do not infer support
from a provider name, deployment flag, or client header. Add an adapter to the
allowlist only alongside its documented wire contract and adapter-level tests.

## Implementation / safety contract

`DeferredToolSelector` creates a compact stable JSON catalog in source schema
order and locally ranks names/descriptions. A hit returns the exact original
schema objects in original relative order (including `required`, parameter
constraints, and extensions). Miss/error returns the entire eager input. The
selection entrypoint requires the deployment flag AND explicit adapter support;
otherwise it returns the exact eager array. Existing request headers are not
read by this code. `v21_deferred_tools_enabled` remains false by default.

Telemetry reports catalog/schema/search byte counts, hit match count, misses,
errors, retries, status, and local search latency. Byte counts are deliberately
not represented as provider tokenizer tokens or billable savings; those require
provider-supported paired measurements and task success observations.

## Evidence and release status

Contract tests exercise exact schema pass-through for OpenAI-compatible requests,
Anthropic's established `parameters` -> `input_schema` translation (including
required fields), stable catalogs, ranked selection, miss/error fallback, and
retry/error telemetry. There is no valid paired provider workload yet: every
registered adapter lacks the deferred-load wire contract, so a treatment request
cannot be sent without inventing protocol semantics. Consequently no request-token
reduction, end-to-end latency, tool-call-failure, or task-success claim is made.
The lane must remain flag-off until an adapter contract exists and paired baseline
vs treatment workload evidence is collected, including actual provider/tokenizer
usage and task success. External vendor percentages are not acceptance criteria.
