TOKEN-SAVER PROXY — HOW TO RUN THE PROXY AND TESTS
====================================================

All commands below assume you're in the project root:
    C:\Users\Burhan\OneDrive\Desktop\AI Tokens Compression\token-saver

A Python virtual environment already exists at .venv. If it's ever missing or
you need to recreate it:

    python -m venv .venv
    .venv\Scripts\pip install -r proxy\requirements.txt


0. ONE-TIME SETUP
------------------
- Copy .env.example to .env if you don't already have one, and review it.
  The defaults are fine for local use; DATABASE_PATH should stay unset so it
  resolves correctly both locally and in Docker.
- Get an OpenRouter API key at https://openrouter.ai/keys. Never paste it
  into chat/logs — set it as an environment variable only.


1. START THE PROXY
-------------------
In a terminal (PowerShell), from the project root:

    .venv\Scripts\uvicorn proxy.main:app --port 8000

Leave this running. It listens on http://localhost:8000 and forwards to
OpenRouter (or whatever UPSTREAM_BASE_URL is set to in .env).

IMPORTANT: uvicorn does NOT auto-reload by default. If you edit any file
under proxy/ or .env, stop this process (Ctrl+C) and restart it, otherwise
you'll be testing stale code.

Quick health check (in another terminal):

    curl http://localhost:8000/health


2. SET YOUR API KEY (in the terminal you'll run tests from)
-------------------------------------------------------------
    $env:OPENROUTER_API_KEY="sk-or-v1-..."

Type this directly at the prompt — don't paste real keys into any chat log
or shared document.


3. RUN THE TEST SUITE (unit tests, no API key / network needed)
-------------------------------------------------------------------
    .venv\Scripts\pytest test\test_proxy.py -q

This covers the classifier, token counting, stats DB, conciseness gating,
and reasoning-control logic using a mocked upstream — nothing real is sent
to OpenRouter.


4. RUN THE DEMO CLIENT (a few sample prompts through the proxy)
-------------------------------------------------------------------
    .venv\Scripts\python test\demo_client.py

Options:
    --model <model-slug>     e.g. --model anthropic/claude-sonnet-5
                              (default: z-ai/glm-5.3-flash)
    --ask "your question"    ask one custom question instead of the samples

Example:
    .venv\Scripts\python test\demo_client.py --model anthropic/claude-sonnet-5

At the end it prints running totals from /stats (tokens saved, cost saved,
avg latency).


5. RUN THE COMPARE SCRIPT (direct vs. proxied, side by side)
-------------------------------------------------------------------
This is the most thorough test: it sends each prompt BOTH directly to
OpenRouter and through the proxy, then reports token counts, cost, latency,
and the full answers for both.

    .venv\Scripts\python test\compare.py

Options:
    --model <model-slug>     default: openai/gpt-4.1-mini
    --proxy <url>            default: http://localhost:8000
    --prompts <file.json>    default: built-in 6 sample prompts;
                              use test\large_prompts.json for longer,
                              more realistic prompts
    --out <file.md>          where full untruncated answers are written
                              (default: test\compare_report.md)

Example — test with Claude Sonnet 5 against the larger realistic prompt set:

    .venv\Scripts\python test\compare.py --model anthropic/claude-sonnet-5 --prompts test\large_prompts.json

After it finishes, open test\compare_report.md to read the full direct vs.
proxied answers side by side (the terminal only shows a 160-char preview of
each). Check that:
    - conversational prompts show real input-token savings via the proxy
    - code/log prompts are passed through with little/no change
    - proxied answers are accurate and don't drift in meaning from direct
    - raw "usage" JSON per prompt (also in the report) doesn't show a big,
      unexplained output-token gap — if it does, check for hidden
      "reasoning_tokens" in completion_tokens_details, which some models
      spend unpredictably regardless of prompt content


6. CHECK CUMULATIVE STATS
-------------------------------------------------------------------
    curl http://localhost:8000/stats
    curl "http://localhost:8000/stats?format=text"

To reset stats, stop the proxy, delete data\stats.db, and restart:

    Remove-Item data\stats.db
    .venv\Scripts\uvicorn proxy.main:app --port 8000


TROUBLESHOOTING
-------------------------------------------------------------------
- "Requests" count or savings look wrong after a fix -> you probably forgot
  to restart uvicorn after editing code. Stop it (Ctrl+C) and start again.
- 404 on every request in compare.py -> proxy isn't running, or --proxy URL
  is wrong.
- Stats not resetting after deleting data\stats.db -> make sure DATABASE_PATH
  isn't overridden in .env (it should be commented out / unset).
